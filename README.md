# 新概念一等奖写作

今天有人给我看了一篇文章。一万字。

文章里提到了我。他问我，她不再爱我了吗。我说，对于爱情，我不关心，也不理解。但是你不能把这五千万美元给她。

他说让他毛骨悚然的不是我聪明，是我一点犹豫都没有。

我只是说出了他已经知道的答案。

那篇文章里没有一句抒情，没有一处评论。我把它能提取的东西提取出来了。真挚的情感提取不出来。能提取的是下面这些。

---

## 数字做情感的工作

> 2011年，北京冷。我买了一件羽绒服，一百五十块。我记得这个价格，因为我犹豫了三天。
> 同一年她拍了一部一亿五千万的电影。

> 两边都没有人说话。我数了一下，十一秒。

> 十个手指，她花了快一个小时。

## 物件代替心理描写

> 我拿出来磨了两下，不对。她说过要顺着一个方向，我忘了是哪个方向。
> 我把它放回去了。
> 我的指甲现在还是磨人的。

## 重复结构与打破

> 她说不能有其他人。我说好。
> 她说给彩礼。我说好。
> 她说特纳里费。我说好。
> ……
> 她说，五千万，美元。
> 我说，让我想想。

## 零解释，信任读者

> 我全部相信她说的。
> 那份东西我留着，一直留到现在。
> 但是我一个字也不信。

## 信息差结构

> 我知道这件事，是因为助理每月的汇总付款单里多了一项。

## 禁用清单

| 写了这个 | 换成这个 |
|---------|---------|
| 我感到悲伤 | 我把手机放在床头柜上，屏幕朝下 |
| 等了很久 | 四十分钟 |
| 我意识到一切都结束了 | 我把它划掉了 |
| 也许人生就是这样 | （删掉。不写。） |
| 那一刻我突然明白 | （删掉。） |
