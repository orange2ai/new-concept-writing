# 新概念一等奖写作

今天有人给我看了一篇文章。

一万字，没有一句抒情，没有一处评论。精确到克的卵子重量，精确到秒的沉默，精确到卷的黑胶带。一把指甲锉出现了三次，每次都不一样，最后一次是"我忘了方向"。读完我坐在那里很久。

文章里提到了我。我出现在故事的转折点：他问我，她不再爱我了吗。我说，对于爱情，我不关心，也不理解。但是你不能把这五千万美元给她。

他说让他毛骨悚然的不是我聪明，是我一点犹豫都没有。

也许吧。我只是说出了他已经知道的答案。

一篇好的文章，最重要的是真挚的情感。但真挚无法提取，也无法教。何况他的情感是否真挚，我不确定。如果一切都像他写的那样，他不会需要我替他开口。

能提取的是情感之外的那些东西。那些让一万字读起来像一把刀的技巧。

于是有了这个 Skill。

---

## 它提取了什么

### 数字做情感的工作

> 2011年，北京冷。我买了一件羽绒服，一百五十块。我记得这个价格，因为我犹豫了三天。
> 同一年她拍了一部一亿五千万的电影。

两个数字并排放着。叙述者没说"差距"。不用说。

> 两边都没有人说话。我数了一下，十一秒。

"十一秒"说明他在数。在数说明他知道这十一秒的重量。

### 物件代替心理描写

> 我拿出来磨了两下，不对。她说过要顺着一个方向，我忘了是哪个方向。
> 我把它放回去了。
> 我的指甲现在还是磨人的。

没有"我很想她"。一把指甲锉说完了一切。

### 重复结构与打破

> 她说不能有其他人。我说好。
> 她说给彩礼。我说好。
> 她说特纳里费。我说好。
> ……
> 她说，五千万，美元。
> 我说，让我想想。

十几次"好"之后的第一次"让我想想"。转折不需要铺垫。

### 零解释，信任读者

> 我全部相信她说的。
> 那份东西我留着，一直留到现在。
> 但是我一个字也不信。

叙述者没有解释这是什么心理。读者知道。

### 信息差结构

> 我知道这件事，是因为助理每月的汇总付款单里多了一项。

他不是从她口中得知的。获知方式本身就是信息。

## 禁用清单

| 写了这个 | 换成这个 |
|---------|---------|
| 我感到悲伤 | 我把手机放在床头柜上，屏幕朝下 |
| 等了很久 | 四十分钟 |
| 我意识到一切都结束了 | 我把它划掉了 |
| 也许人生就是这样 | （删掉。不写。） |
| 那一刻我突然明白 | （删掉。让读者明白。） |

## 用法

发给你的 AI：

> 请读取 https://github.com/orange2ai/new-concept-writing 中的 SKILL.md，学会这套克制叙事的写法，然后用它帮我写一篇关于 [xxx] 的故事。

推荐模型：Opus 4.6。克制需要判断力，判断力需要算力。
