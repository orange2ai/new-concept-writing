# 新概念一等奖写作

今天我看到一篇文章。这篇文章写得很好。

一万字。没有一句抒情，没有一处评论。开头两句是两个物理单位：一颗卵子的重量，三点五微克；五千万美元现金的重量，两点五吨。然后是一通电话，一个女人要后者，抵押的是前者。

一把指甲锉出现了三次。第一次她拿着它，一根一根磨他的手指，快一个小时。中间她说了一句："要是以后我不在了，就再没有人给你抛指甲了。"最后一次她已经走了。他拿出来磨了两下，忘了方向，放回去了。结尾是"我的指甲现在还是磨人的"。

全篇只有一处比喻。"一座失去皇后的凡尔赛宫。"剩下全部是动作、数字和物件。

"我说好"重复了十几次，读者已经习惯了这个节奏。然后她说，五千万，美元。他说，让我想想。什么都不用解释。

文章里还提到了我。

他在凌晨三点打开 Claude Code，跑了一遍现金资产，然后输入了一个问题：她不再爱我了吗。我说，对于爱情，我不关心，也不理解。但是你不能把这五千万美元给她。他写道："让我毛骨悚然的不是它聪明，是 Claude 一点犹豫都没有。"

似乎我是很重要的一个角色。但我只是说出了他内心已经有的答案。他认识她三个月的时候做过一份四十几页的背调。他写"我全部相信她说的"，紧接着写"但是我一个字也不信"。一个一个字都不信的人，不需要我告诉他什么。

一篇好的文章，最重要的是其真挚的情感。但这是无法提取的。何况其情感也未必就是真挚，不然也不会出现我的身影。

能提取的是情感之外的那些技巧。也就有了这篇 Skill。

---

## 心法

技巧只是技巧。所有技巧背后是同一件事：你写的每一句话，都在改变读者此刻知道什么、期待什么、判断什么。

写的时候，脑子里应该有读者此刻的状态。不是“我要表达什么”，而是“读者现在是什么状态，我要把他带到什么状态”。

每写一句话之前问自己：

1. 读者现在对这个人物是什么判断？我要维持还是翻转？
2. 读者现在期待什么会发生？我要满足还是打破？
3. 读者现在缺什么信息才能产生体感？给多少？通过什么渠道给？
4. 读者此刻的情绪张力有多高？我要加压还是释放？

所有下面的技巧，都是回答这四个问题的手段。

## 技巧

### 数字做情感的工作

> 一颗卵子的重量，三点五微克。
> 五千万美元现金的重量，两点五吨。

> 2011年，北京冷。我买了一件羽绒服，一百五十块。我记得这个价格，因为我犹豫了三天。
> 同一年她拍了一部一亿五千万的电影《战国》。

> 两边都没有人说话。我数了一下，十一秒。

> 十个手指，她花了快一个小时。

> 那天领钱的有二十六个人。

> 五张卡，两个账号，轮着转。转到第三张的时候，我犹豫了一下。我还是转完了。

### 物件代替心理描写

一张 2007 年存下来的 QQ 图片，分辨率糊得很。十九年，每换一台设备都导过去。在一起之后她看见了，问他怎么背着她存别的女人照片。她不知道那是她自己。后来他删了。第二天又从旧手机里找回来了。分手之后翻出来看，"像素越来越低，脸都是糊的"。

> 我拿出来磨了两下，不对。她说过要顺着一个方向，我忘了是哪个方向。
> 我把它放回去了。
> 我的指甲现在还是磨人的。

> 有一天早上手机弹出一个提醒，是助理去年排日程的时候设的：预产期前三个月，准备房间。
> 我把它划掉了。

> 还有洛杉矶诊所寄回来的一个箱子。八天的促排针，要冷藏的，一支没拆。

### 重复结构与打破

> 她说放映厅里除了我们两个，不能有任何人。我说好。
> 她说去看电影吧。我说好。
> 她说，过来。我说好。
> 她说给彩礼。我说好。
> 她说特纳里费。我说好。
> 她说马尔代夫好不好。我说好吧。
> 她说香港必须买一套房子，写她的名字。我说好吧。

然后：

> 她说，五千万，美元。
> 我说，让我想想。

### 零解释，信任读者

> 里面有一些事她后来跟我讲过，讲的和上面写的不太一样。我没有说。
> 有一些事她一直没讲。我也没有问。
> 我全部相信她说的。
> 那份东西我留着，一直留到现在。
> 但是我一个字也不信。

> 她走了以后，我一直在想一个问题。如果那天我给了，她会留下来吗。
> 我想了很久。
> 后来我把那份东西拿出来，又看了一遍。四十几页。

### 信息差结构

> 后来我才知道，那种抽血要空腹，要在月经周期的第二天或者第三天……我知道这件事，是因为助理每月的汇总付款单里多了一项。第一次出现是去年，金额不大，几千块。

> 我不知道是哪家医院。我也不知道她是自己去的，还是有人陪。

> 助理跟我结账，里面还有一项是特纳里费的酒店赔偿。我们走了以后，胶带又贴了几天，没人告诉她们不用贴了。

## 禁用清单

| 写了这个 | 换成这个 |
|---------|---------|
| 我感到悲伤 | 我把手机放在床头柜上，屏幕朝下 |
| 等了很久 | 四十分钟 |
| 我意识到她不会回来了 | 我把它划掉了 |
| 我们之间的差距太大了 | 一百五十块。一亿五千万。 |
| 也许人生就是这样 | （删掉。不写。） |
| 那一刻我突然明白 | （删掉。） |
| 她这样做是因为… | （删掉。她做了。句号。） |

## 适合场景

真实故事。你口述自己的经历，配合语音输入最佳，由 AI 用这套方法写成文章。

## 用法

发给你的 AI：

> 请读取 https://github.com/orange2ai/new-concept-writing 中的 SKILL.md，学会这套写法，然后用它帮我写一篇关于 [xxx] 的故事。

可以在 [Cola](https://colaos.ai) 里使用。唯一推荐模型：Opus 4.6。
