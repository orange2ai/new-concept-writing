# 新概念一等奖写作

## 起源

读到一篇文章。一万字，没有一句抒情，没有一处评论。读完坐在那里很久。

试着找它为什么有力量。找到了几样东西：

精确的数字在做情感的工作。一百五十块的羽绒服，犹豫了三天。同一年，一亿五千万的电影。叙述者没说"差距"。两个数字并排放在那里，读者自己知道了。

物件在替人说话。一张存了十九年的 QQ 图片，每换一台设备都导过去。一把指甲锉，她教过他怎么用，后来他忘了方向。一卷黑胶带，她走了以后没人通知那两个女孩不用贴了，她们又贴了好几天。

"我说好"重复了十几次，读者已经习惯了这个节奏。第一次没说好的时候，什么都不用解释。

全篇一处比喻。零处评论。作者信任读者能接住所有没说出来的东西。

这些技巧可以提炼。这个 Skill 就是提炼后的结果。

## 它教什么

六条规则。每条都有对应的禁区。

### 数字做情感的工作

> 两边都没有人说话。我数了一下，十一秒。

"十一秒"说明他在数。在数说明他知道这十一秒的重量。不写"沉默了很久"。写几秒。

> 十个手指，她花了快一个小时。

不写"很耐心"。写时间。读者自己判断那是什么。

### 物件代替心理描写

> 有一天我用指甲刀剪指甲，剪完摸了一下，是尖的。
> 我想起来抽屉里还有那个东西，她留下的。
> 我拿出来磨了两下，不对。她说过要顺着一个方向，我忘了是哪个方向。
> 我把它放回去了。
> 我的指甲现在还是磨人的。

五句话。没有"我很想她"。一把指甲锉说完了一切。

### 重复结构与打破

> 她说不能有其他人。我说好。
> 她说去看电影。我说好。
> 她说给彩礼。我说好。
> 她说特纳里费。我说好。
> ……
> 她说，五千万，美元。
> 我说，让我想想。

十几次"好"之后的第一次"让我想想"。这就是转折。不需要任何铺垫。

### 零解释，信任读者

> 我全部相信她说的。
> 那份东西我留着，一直留到现在。
> 但是我一个字也不信。

三句话。叙述者没有解释这是什么心理。读者知道。

### 信息差结构

> 后来我才知道，那种抽血要空腹……我知道这件事，是因为助理每月的汇总付款单里多了一项。

他不是从她口中得知的。是从付款单里发现的。获知方式本身就是信息。

### 结尾是画面

> 凌晨三点的香港，什么都没有发生。

不总结。不升华。一个城市画面。读者知道一切都发生了。

## 禁用清单

| 写了这个 | 换成这个 |
|---------|---------|
| 我感到悲伤 | 我把手机放在床头柜上，屏幕朝下 |
| 等了很久 | 四十分钟 |
| 她很在意隐私 | 她说周围不能有人 |
| 我意识到一切都结束了 | 我把它划掉了 |
| 也许人生就是这样 | （删掉。不写。） |
| 那一刻我突然明白 | （删掉。让读者自己明白。） |

## 用法

Cola Skill。放进 `~/.cola/skills/new-concept-writing/`。

上传素材或口述经历，说"用新概念写作的方式写"。

推荐模型：Opus 4.6。克制需要判断力，判断力需要算力。
