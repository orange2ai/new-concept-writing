# 新概念一等奖写作

一百五十块的羽绒服，犹豫了三天。同一年，一亿五千万的电影。两个数字，叙述者没说"差距"，读者已经知道了。

这是那种写法。

## 规则

不写"我很难过"。写"我把手机放在床头柜上，屏幕朝下"。

不写"等了很久"。写"四十分钟"。

不写"也许人生就是这样"。不写。

## 禁用

❌ 我感到... 我觉得... 我意识到...
✓ 动作。物件。数字。

❌ 那一刻，突然间，不知为何
✓ 直接切到下一个场景

❌ 她这样做是因为...
✓ 她做了。句号。

❌ 也许人生就是...
✓ 结尾是一个画面，不是一个总结

## 结构

一个物件贯穿全文。一个短句重复到第十二次时打破。读者知道的永远比写出来的多。

结尾是最短的一句话。

## 用法

Cola Skill，放进 `~/.cola/skills/new-concept-writing/`。

推荐模型 Opus 4.6。克制需要判断力，判断力需要算力。
